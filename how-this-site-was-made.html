How This Site Was Made

This page explains how this website was created — step by step — by a beginner, for beginners.

Step 1: Writing the Content

The actual text for the pages was written first. The goal was to explain programming concepts in simple language, without assuming prior knowledge.

Step 2: Generating HTML with Python

Some pages were generated using Python. Python was used to automatically create HTML files by writing text into .html files.

This showed how programming languages can work together instead of competing with each other.

Step 3: Styling with CSS

Basic CSS was added to make the site readable and clean. Colors, spacing, fonts, and layout were all handled using CSS inside the HTML files.

Step 4: Uploading to GitHub

All the files were uploaded to a GitHub repository. Each page on the site is just a normal .html file stored there.

Step 5: Publishing with GitHub Pages

GitHub Pages was used to turn those files into a live website. Once enabled, GitHub automatically served the pages on the web.

Why This Site Exists

This site exists to show that you don’t need to be an expert to start building things. Learning happens by experimenting, breaking stuff, and fixing it.
